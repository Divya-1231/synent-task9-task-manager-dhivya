# Full Stack Task Manager

## About
A full-stack Task Management Web Application developed using Python Flask and SQLite.

## Features
- User Registration
- User Login and Logout
- Secure Password Hashing
- Add New Tasks
- Update Tasks
- Delete Tasks
- User-specific Task Management
- SQLite Database Integration
- Responsive User Interface

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS
- Werkzeug

## Installation

Install the required packages:

```bash
pip install -r requirements.txt
```

## Run the Application

```bash
python app.py
```

Open in your browser:

http://127.0.0.1:5000
